# Skycast-web
🌤️ WeatherSkyCast

A modern and responsive weather application built using HTML, CSS, and JavaScript.

🚧 Project Status

This project is currently under construction.

New features are being actively developed and improved. The current version is functional but not yet complete.

✨ Features Implemented
Current weather information
Real-time date and time display
City-based weather search
Temperature display in Celsius
Humidity information
Wind speed information
Dark/Light mode toggle
Responsive UI design
🔨 Features Under Development
Hourly weather forecast
Air Quality Index (AQI)
Dynamic weather alerts
Weather recommendations
Local city highlights
Weather-based icon updates
Enhanced UI/UX improvements
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6+)
OpenWeather API
Remix Icons
